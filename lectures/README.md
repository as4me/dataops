## Как пользоваться

1. Читайте главы по порядку — каждая опирается на предыдущие.
2. В конце глав есть **ключевые выводы** и **вопросы для самопроверки**.
3. После главы выполняйте соответствующую [практику](../practices/README.md).
4. Параллельно собирайте [итоговый проект](../docs/TZ.md).
5. Источники данных: [DATA_SOURCES.md](../docs/DATA_SOURCES.md).
