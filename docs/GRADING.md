Максимум: **100 баллов**.

| Раздел | Баллы | На что смотрят |
|--------|------:|----------------|
| Архитектура и воспроизводимость | 10 | Слои RAW→MART, Docker Compose, запуск «с нуля», отсутствие секретов в Git |
| Data Ingestion | 10 | ≥3 источника, метаданные загрузки, ошибки, идемпотентность |
| Оркестрация | 10 | DAG, зависимости, retry/timeout, логи, обработка ошибок |

| Git и управление изменениями | 10 | ветки, PR, история, Analytics as Code |
| CI/CD | 10 | автопроверки на PR, fail при критических ошибках |

| Документация | 5 | README по требованиям ТЗ, lineage, схема |

## Зачёт

Зачёт возможен только при выполнении **минимальных требований** из [TZ.md](TZ.md) (раздел 28), даже если сумма баллов формально близка к порогу за счёт отдельных сильных частей.

## Дополнительные баллы

Доп. задания (streaming, catalog, advanced observability, contracts, IaC, cloud) учитываются на усмотрение преподавателя и **не заменяют** обязательный минимум.
